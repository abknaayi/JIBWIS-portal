# JIBWIS MEMBER PORTAL

### Digital Membership Registration and Management System

Welcome to the official JIBWIS Member Portal project.

## About the Project

The JIBWIS Member Portal is a digital platform designed to support membership registration, member information management, communication and organisational administration.

## Key Features

- Member Registration
- Secure Member Login
- Member Dashboard
- Membership Profiles
- Members Directory
- Events and Activities
- Lectures and Announcements
- Branch and Unit Information
- Administrative Support

## Technologies

- HTML5
- CSS3
- JavaScript
- Firebase

## Project Objective

To improve membership administration, accessibility, communication and digital organisation.
